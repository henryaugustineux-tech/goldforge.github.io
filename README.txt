AXIS HAUS — LOCAL VERSION
=========================

1. Keep all files in this folder.
2. On Windows, double-click start-local.bat.
3. Open http://localhost:8000 in Chrome/Edge.

The supplied page was a Webflow export. The original CSS, images and Webflow
runtime are referenced from their CDN, so an internet connection is still
needed for the original visual assets/scripts.

The contact form has been changed to a local-only success interaction instead
of trying to submit to Webflow.

If you want a TRUE OFFLINE version (all CSS, JavaScript, fonts and images stored
inside this folder), the external Webflow assets need to be downloaded from the
original site/CDN and then their references rewritten to local paths.
